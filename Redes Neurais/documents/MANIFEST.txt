🔷 JUPYTER NOTEBOOKS (6 arquivos, ~2000 linhas de código)
   
   1. NN_01_DataGeneration.ipynb
      - Gera 100,000 amostras sintéticas balanceadas
      - TAGs caóticas (tent map + quadrática)
      - Canal Rayleigh + AWGN
      - Features: [correlator, h_est, SNR, energy]
      - Output: dataset_nn_100k.h5 (~50 MB)
      - Tempo: 20-30 min (CPU), 5-10 min (GPU)
      
   2. NN_02_DNN_Correlator.ipynb ⭐ RECOMENDADO
      - Referência: Braca et al. (2022)
      - 3 camadas densas + BatchNorm + Dropout
      - Input: 4D features → Output: P(autêntico)
      - Framework: TensorFlow/Keras
      - Output: model_dnn_correlator_final.h5, results_dnn_correlator.png
      - Tempo: 5-10 min
      - Params: ~100k
      
   3. NN_03_CNN_SignalProcessing.ipynb
      - Referência: "Binary Case using Deep Learning"
      - 2 blocos Conv1D + MaxPool + Flatten + Dense
      - Aprende padrões locais na sequência de sinais
      - Framework: PyTorch
      - Output: model_cnn_best.pth, results_cnn.png
      - Tempo: 10-15 min
      - Params: ~50k
      
   4. NN_04_LSTM_Rayleigh.ipynb
      - Referência: "Classification of Stochastic Systems"
      - Bi-LSTM 64→32 + Dense layers
      - Modela dinâmica temporal do canal fading
      - Framework: PyTorch
      - Output: model_lstm_best.pth, results_lstm.png
      - Tempo: 15-20 min
      - Params: ~80k
      
   5. NN_05_Ensemble_Hybrid.ipynb
      - Referência: Braca et al. (Ensemble Methods)
      - Combina: DNN + CNN + LSTM
      - Estratégias: Average + Weighted (meta-learner)
      - Output: results_ensemble.png
      - Tempo: 10 min
      - Framework: Hybrid (TF + PyTorch)
      
   6. NN_06_Comparison_vs_Baseline.ipynb
      - Compara NN vs Monte Carlo baseline
      - Métricas: FNR, FAR, Accuracy, AUC
      - Visualizações: ROC curves, performance bars
      - Output: comparison_nn_vs_baseline.png + relatório
      - Tempo: 5 min

📖 HOW TO USE
================================================================================

Quick Start:
   1. Read: GUIA_EXECUCAO_PT-BR.md (Portuguese) or README.md (English)
   2. Install: pip install -r requirements.txt (see notebooks)
   3. Run: jupyter notebook NN_01_DataGeneration.ipynb
   4. Then: Execute NN_02 through NN_06 in order
   5. View: Generated .png files for results

Customization:
   - Change SNR range in NN_01 (line: SNR_RANGE = (8, 12))
   - Change L range in NN_01 (line: L_RANGE = (512, 1024))
   - Change dataset size in NN_01 (line: NUM_SAMPLES = 100000)
   - Modify model architectures in NN_02-NN_04
   - Adjust learning rates, dropout, epochs as needed

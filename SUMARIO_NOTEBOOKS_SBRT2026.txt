## ✅ PIPELINE ESSENCIAL (5 Notebooks)

### 1. NN_01_DataGeneration.ipynb
- Gera dataset: 350k amostras, SNR 0-30 dB, estratificado
- Output: `dataset_cnn_yeq_0_30dB.h5`
- **Executar**: Sempre primeiro

### 2. NN_02_DNN_Correlator_GPU.ipynb  
- **Modelo principal**: 1D CNN com z_eq (sinal residual bruto)
- **Entrada**: z_eq ∈ ℝ¹⁰²⁴
- **Desempenho**: P_D = 85.6% @ 0 dB ⭐
- **Por que funciona**: Conv1D aprende correlação implicitamente

### 3. NN_02b_4feat_DNN_Aligned.ipynb
- **Comparação**: DNN densa com features manualmente extraídas
- **Entrada**: [|τ|, ĥ, SNR, E] (4 escalares) ou [|τ|, ĥ] (2 escalares)
- **Resultado chave**: 2-feat = 85.6%, 4-feat = 82% (piora!)

### 4. NN_07_DNN_vs_MonteCarlo_Comparison_GPU.ipynb
- **Método D3F**: threshold com α=10⁻⁷ (sem simular 10⁷ amostras)
- **Valida**: extrapolação gaussiana de escores sob H0
- **Output**: Tabelas P_D vs SNR

### 5. NN_08_Architecture_Comparison.ipynb
- **Valida D3F**: DNN-2feat vs CNN-2feat vs SVM linear
- **Diferença**: apenas 0.4pp (85.6% vs 85.2%)
- **Conclusão**: arquitetura é irrelevante com 2-features

## 🎓 Insights do Artigo (com suporte dos notebooks)

### 1. Redundância de Features (NN_02b Ablation)
```
Núcleo [|τ|, ĥ]           → 85.6%  ✅
Núcleo + SNR              → 82.2%  ❌ Piora 3.4pp
Núcleo + E                → 82.0%  ❌ Piora 3.6pp
Núcleo + SNR + E          → 81.5%  ❌ Piora 4.1pp
```
**Razão**: Quando a rede tem ĥ (estimativa de ganho), todas as outras features
são derivadas redundantes → aumentam dimensionalidade → degradam generalização.

### 2. Sinal Bruto Não Funciona em Baixo SNR (NN_02 vs NN_12)
```
Baixo SNR (0-5 dB):
  - CNN com z_eq (1024d):  85.6% ✅
  - DNN com z_eq (1024d):  <75%  ❌ FALHA

Por que?: Sem extração de features, a rede não consegue
fazer integração coerente em sinal ruidoso.
```

### 3. Arquitetura é Secundária (NN_08 Comparação)
```
2-feature CNN-1D:   85.2%
2-feature DNN:      85.6%
Diferença:          0.4pp (praticamente ignorável)
```
**Conclusão D3F**: Quando dados satisfazem IID e escores são 
calibrados com BCE, a arquitetura não importa.

### 4. Método Clássico Não Adapta (NN_07 D3F)
```
Clássico [|τ|] com limiar fixo: 8.1% @ 0 dB
DNN [|τ|, ĥ] com threshold D3F: 85.6% @ 0 dB
Diferença: 10x melhora
```
**Por que**: ĥ permite à rede aprender limiar adaptativo 
em função do ganho Rayleigh variável (princípio CFAR).
